# Aplikasi_Penjualan_Laravel
Aplikasi Penjualan Toko ini merupakan sistem berbasis web yang telah dikembangkan menggunakan framework Laravel dengan dukungan database MySQL. Sebelumnya dibangun menggunakan PHP Native, sistem ini kini telah di-upgrade ke Laravel untuk meningkatkan performa, keamanan, serta kemudahan dalam pengelolaan dan pengembangan aplikasi.
